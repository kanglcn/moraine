# 03 DS processing

Pipeline: `examples/03_ds.toml`. Tutorials: `nbs/Tutorials/CLI/Xinpu/03_ds.ipynb`, `nbs/Tutorials/CLI/CampiFlegrei/03_ds.ipynb`. Needs `01_load`.

```bash
moraine run examples/03_ds.toml --workdir WORK
```

Set `[vars] shape` to the (nlines, width) of `raw/rslc.zarr` and `[defaults] cuda = false` without a GPU.

## Steps

1. **SHP**: `shp-test` runs a two sample Kolmogorov-Smirnov test between each pixel and the pixels in its
   window (11 x 11 with `az_half_win = r_half_win = 5`); `select-shp` keeps p < `p_max` (0.05) and counts
   them (`ras_shp_num.zarr`, 0..121).
2. **DS candidates**: pixels with at least 50 SHPs (`pc-logic-ras`, `ras>=50`).
3. **Coherence + phase linking + temporal coherence per raster chunk**: `ras2pc-ras-chunk` splits the
   SHPs of the candidates by raster chunk; `emperical-co-emi-temp-coh-pc` estimates the coherence
   matrix, runs EMI phase linking and computes the DS temporal coherence without storing the full
   coherence matrices. (`emperical-co-pc` + `emi` + `ds-temp-coh` do the same in separate steps and keep
   the coherence.)
4. **Hilbert order**: `pc-hix`, `pc-sort` (writes the sorted gix and the sorting key), `pc-concat` merges
   the per-chunk results with both keys.
5. **Refinement**: EMI quality in [1.0, 1.05] AND temporal coherence in [0.8, 1.0]
   (`pc-logic-pc` twice, `pc-intersect`), then `pc-select-data` and `ras2pc` for e/n.

Outputs (WORK/ds/): all candidates `ds_can_{hix,gix,ph,emi_quality,t_coh}.zarr`; refined DS
`ds_hix.zarr`, `ds_ph.zarr` (n_points, nimages) unit amplitude, `ds_gix.zarr`, `ds_e.zarr`, `ds_n.zarr`;
per-chunk data in `ds/chunks/` (can be deleted afterwards).

## Parameters

- Window: larger windows find more SHPs but blur details; 11 x 11 is common, 7 x 7 for small features.
- `p_max`: 0.05. Minimum SHP number: 50 of 121 here; scale it with the window size.
- Refinement: EMI quality close to 1 means the coherence matrix fits the phase linking model; the upper
  bound (1.05) and the temporal coherence (0.8) control how many DS are kept. If too few points remain,
  loosen them or use `pc-union` instead of `pc-intersect`.

## Expected results (sample data)

| result | sample value | sane range |
|---|---|---|
| `ras_shp_num_pyramid` | p50 12, p99 103, max 121 | 0..(window size) |
| DS candidates (>= 50 SHP) | 732 727 | |
| `ds_can_t_coh_pyramid` | p50 0.77, p01 0.04, max 0.9999 | 0..1 |
| `ds_can_emi_quality_pyramid` | p50 1.04, p99 1.42, p01 -35, min -7e5 | mostly >= 1; negative values are expected (see below) |
| refined by EMI quality | 404 013 | |
| refined by temporal coherence | 381 992 | |
| refined DS (`ds_hix`) | 293 814 | |
| `ds_ph` amplitude | 1.0 | exactly 1 |

Run time: about 1 minute with a GPU.

EMI quality < 1, even strongly negative, is expected for candidates whose coherence matrix is not
regular (not positive definite); the refinement (EMI quality in [1.0, 1.05]) removes them. Sample: 4.6 %
of the candidates below 1 (3.6 % negative), none among the refined DS. Mention it to the user only if the
fraction is large (e.g. > 20 %): the coherence matrices are then poorly estimated (too few SHPs).

## Checks

- `moraine info ds/ras_shp_num_pyramid ds/ds_can_t_coh_pyramid ds/ds_can_emi_quality_pyramid`.
- `moraine quicklook ds/ds_can_t_coh_pyramid -o tcoh.png`: DS on homogeneous areas (fields, slopes).
- `moraine quicklook ds/ds_ph_pyramid --show intf_seq --index I -o ds_intf.png`: the phase linked
  interferograms of the refined DS should be much smoother than the raw ones.

## Problems

- Very few candidates: lower the minimum SHP number or enlarge the window.
- Memory: `emperical-co-emi-temp-coh-pc` holds one raster chunk at a time; reduce `chunks` (e.g.
  `[500, 500]`) or `batch_size`.
