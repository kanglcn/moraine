# 02 PS candidates

Pipeline: `examples/02_ps.toml`. Tutorials: `nbs/Tutorials/CLI/Xinpu/02_ps.ipynb`, `nbs/Tutorials/CLI/CampiFlegrei/02_ps.ipynb`. Needs `01_load`.

```bash
moraine run examples/02_ps.toml --workdir WORK
```

Set `[vars] shape` to the (nlines, width) of `raw/rslc.zarr` and `[defaults] cuda = false` without a GPU.

## Steps

Two candidate sets are merged:

1. **Amplitude dispersion index** (`amp-disp`, ADI = std / mean of the amplitude over time). Stable
   scatterers have a low ADI. Candidates: `ras<0.4` (`pc-logic-ras`).
2. **Noise2Fringe temporal coherence**: `image-pairs` (bandwidth 1, sequential pairs) -> `n2f` filters
   the interferograms -> `temp-coh` compares filtered and raw phase. Candidates: `ras>0.58`.
3. `pc-union` of both sets, `pc-hix` + `pc-sort` to hilbert order, `ras2pc` takes rslc, e/n, lon/lat and
   ADI of the candidates.

Outputs (WORK/ps/): `ps_can_hix.zarr` (n_points,), `ps_can_rslc.zarr` (n_points, nimages),
`ps_can_{e,n,lon,lat,adi}.zarr`; rasters `ras_adi.zarr`, `ras_temp_coh.zarr`, `ras_n2f_intf.zarr`;
pyramids `ras_adi_pyramid`, `ras_temp_coh_pyramid`, `ps_can_adi_pyramid`.

## Parameters

- ADI threshold: 0.25-0.4 is common; lower = fewer, more stable points. With few images (< ~20) the ADI
  is noisy, so the n2f criterion matters more.
- n2f temporal coherence threshold: 0.5-0.7; the tutorial uses 0.58.
- `n2f` needs the models (`moraine.download_dl_model()`) and PyTorch; it is much faster with `cuda`.

## Expected results (sample data, 2500 x 1834 x 17)

| result | sample value | sane range |
|---|---|---|
| `ras_adi_pyramid` | p50 0.55, p01 0.30, p99 1.01, min 0.06 | ADI >= 0; p50 roughly 0.3-1 |
| `ras_temp_coh_pyramid` | p50 0.29, p99 0.84, max 0.998 | 0 <= t_coh <= 1 |
| candidates ADI < 0.4 | 390 525 | a few % to ~30 % of the pixels |
| candidates t_coh > 0.58 | 374 452 | |
| merged `ps_can_hix` | 634 158 (14 % of the pixels) | |

Run time: about 30 s with a GPU.

## Checks

- `moraine info ps/ras_adi_pyramid ps/ras_temp_coh_pyramid`: values within the ranges above, no warnings.
- `moraine quicklook ps/ras_temp_coh_pyramid -o tcoh.png`: high coherence on built-up / rocky areas,
  low on vegetation and water.
- `moraine quicklook ps/ps_can_adi_pyramid -o ps.png`: candidates spread over the stable areas.

## Problems

- Almost no candidates: check the ADI distribution; with a short stack raise the ADI threshold or rely
  on the n2f set.
- `n2f` fails with a missing model file: run `python -c "import moraine; moraine.download_dl_model()"`.
- CUDA out of memory: only one GPU pipeline at a time; or set `cuda = false`.
